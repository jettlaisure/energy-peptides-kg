# Label artwork

Use **current-print/** for the current owner-selected print set: 22 SKUs in Navy, Graphite and Black. Product USES edges now point to the three current process PDF masters for each SKU. Foil pairs, editable SVGs, previews, dimensions, hashes and a 100% size proof are in that folder. Read current-print/README.md before printing.

The PNG files directly in this directory are historical source artwork. They remain for photo provenance and older references; do not send them to the printer as the current design. Website product photographs are separate assets in seeds/15_product_photos.yaml.

Standard trim 40 × 20 mm; only NAD+ is larger, 44.225641 × 22 mm. All current PDF masters have 1 mm bleed. Fine textured matte is physical stock, not an image texture.
